# Slovenščina Korak za Korakom — Mobile App

The iOS, Android, and web client for the **Slovenščina Korak za Korakom** platform
([slovenscinakzk.com](https://slovenscinakzk.com)) — a Slovenian-language learning service.

Built with Expo / React Native (SDK 58), Expo Router, and Clerk authentication, from a
single codebase.

> **Status:** early development — authentication is implemented; learning and booking
> features are still to come.
